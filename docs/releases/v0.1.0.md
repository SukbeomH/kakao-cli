# v0.1.0 — Apple Silicon preview

Apple Silicon Mac에서 공식 Android 카카오톡을 독립 실행하는 설치 패키지다.
CPU 2개·메모리 4GiB·디스크 20GiB의 Lima VM을 사용한다.

## 설치

첨부된 `kakao-cli-0.1.0-macos-arm64.tar.gz`와 `SHA256SUMS.txt`를 같은 폴더에 내려받는다.

```bash
shasum -a 256 -c SHA256SUMS.txt
tar -xzf kakao-cli-0.1.0-macos-arm64.tar.gz
cd kakao-cli-0.1.0-macos-arm64
brew install lima
bash scripts/setup-macos.sh
```

- 접속: http://127.0.0.1:8800 → QR 로그인은 직접 진행.
- 종료: `limactl stop kakao` (데이터 보존).
- APK·이미지는 설치 시 다운로드하므로 인터넷이 필요하다.
- 카카오톡 26.8.3·ADBKeyBoard의 파일 해시와 서명 인증서를 확인한 뒤 설치한다.
- 기존 앱은 재설치·업데이트하지 않는다. VM 디스크·ADB 키·계정 데이터는 첨부하지 않는다.
- 태블릿 로그인 시 기존 VM/태블릿 세션이 해제될 수 있다.

## 변경과 확인 범위

- Mac 독립 실행 가이드, 다운로드 manifest와 설치기 추가.
- binder 0660 권한으로 발생한 Android 접근 실패 수정(전용 Lima VM 내부 0666).
- 비활성 ADBKeyBoard 인식 수정(`ime list -a -s`).
- Git 없는 릴리즈 폴더의 코드 전송 지원, Mac 확장 속성 tar 경고 방지.
- Ubuntu·redroid·Python 컨테이너 이미지 digest 고정.
- 실제 수동 설치에서 Android healthy, doctor ok, 웹 콘솔·로그인 화면·정상 종료 확인.
- 신규 설치기 자동 흐름은 모의 테스트로 검증. 계정 로그인·DB 수신·송수신·재부팅 후 로그인 유지는 미검증.
