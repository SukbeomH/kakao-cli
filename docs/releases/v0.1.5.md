# v0.1.5 — Tailscale VM VPN 관리 (preview)

`kakao-cli 0.1.5` / 공통 `android-console 0.1.2` 배포입니다.
CLI·TUI·웹 UI에서 Linux VM의 Tailscale 로그인, 상태 확인, 온라인 Exit node 선택,
우회 해제를 진행합니다. 기존 클립보드·우클릭·키보드·한글 조합 기능도 유지합니다.

## 변경 사항

- **CLI**: `kakao vpn status/login/exit/direct/tui`, `login --open`, `--url`, `--json`을 제공합니다.
  `android-console vpn`도 같은 구현을 사용합니다(기본 포트 8801, Kakao는 8800).
- **TUI**: `kakao vpn tui` 또는 기존 TUI의 방 목록에서 `v`로 VPN 화면을 엽니다.
  상태 요청은 비동기로 처리하고, `L` 로그인·`O` 인증 URL 열기·Enter 적용·`D` 우회 해제를 지원합니다.
- **웹 UI**: 상단 **VM VPN** 패널에서 인증 링크, 온라인/오프라인 Exit node,
  경로 적용·해제를 제공합니다. 열린 동안 상태를 갱신하며 닫으면 인증 링크와 목록을 지웁니다.
- **VM 전용 제어**: 제한된 Linux 에이전트가 Unix 소켓을 통해 필요한 동작만 처리합니다.
  macOS의 Tailscale·기본 경로·DNS를 변경하지 않으며, 임의 명령이나 인증키 입력을 받지 않습니다.
  원본 tailscaled 소켓과 Docker 소켓은 웹 컨테이너에 마운트하지 않습니다.
- **선택적 설치**: `scripts/setup-vm-vpn.sh`와 `deploy/compose.network.yaml`을 추가했습니다.
  재기동에 필요한 커널 모듈을 설정하고, 관리 서비스는 tailscaled와 함께 재시작합니다.
  VM의 활성화 표식으로 후속 webui 갱신 때 설정을 유지합니다. 기본 설치에는 VPN이 활성화되지 않습니다.

## 기존 Kakao VM 갱신

```sh
git pull --ff-only
# VM이 중지 상태라면 먼저 실행
limactl start kakao
# Tailscale 및 관리 서비스가 이미 준비된 VM
./scripts/setup-vm-vpn.sh kakao
./scripts/lima-compose.sh up -d --no-deps --build webui
kakao vpn status --json
```

**최초 사용 시에는 VM 안에 공식 Linux Tailscale 패키지를 먼저 설치**해야 합니다.
이 준비 스크립트가 패키지를 다운로드하거나 계정 인증을 대신하지는 않습니다.
로그인 URL에서 기존 Exit node가 속한 계정으로 새 VM 장치 가입을 승인한 뒤 Exit node를 선택합니다.
조직 CA가 필요한 환경의 tailscaled 전용 인증서 설정도 [VM VPN 가이드](../vm-vpn.md)에 있습니다.
맥의 Tailscale 인증 상태를 VM에 복제하지 않습니다.

VPN을 쓰지 않는 기존 설치는 webui만 갱신하면 됩니다. VM의 Android 데이터·로그인 상태는 유지하고,
갱신 후 브라우저를 새로고침합니다. 전체 설치 방법은 [배포 가이드](../release.md)를 참고하세요.

```sh
kakao vpn login --open
kakao vpn status
kakao vpn exit 100.64.0.1  # status에 표시된 온라인 Exit node IP로 대체
kakao vpn direct         # VM 우회만 해제, 로그인은 유지
```

원격 Linux 서버에서는 관리 에이전트를 VM 호스트에 준비한 뒤 기존 Compose 파일에
`-f deploy/compose.network.yaml`을 추가합니다. 기본 콘솔은 인증 없이 loopback에만 노출하므로
원격 접근에는 SSH 터널 등 인증된 경로를 사용합니다.

독립 `android-console`도 공통 VPN 클라이언트와 서버 API를 포함합니다. 독립 런타임 번들은
VPN 비활성화 상태로 시작하며, 에이전트와 `--network-socket`/환경변수 연결을 별도로 준비해야 합니다.

| `android-console-0.1.2-macos-arm64.tar.gz` | 독립 Android 콘솔 설치기·공통 모듈 소스 |

| `SHA256SUMS.txt` | 위 6개 파일의 SHA-256 |

Python 설치 시에는 두 wheel을 함께 지정합니다.

```sh
python3 -m pip install ./android_console-0.1.2-py3-none-any.whl ./kakao_cli-0.1.5-py3-none-any.whl
```

Tailscale 패키지·인증 정보·CA 번들·VM 디스크·Android 데이터·ADB 키는 배포물에 포함하지 않습니다.
카카오톡·ADBKeyBoard APK와 이미지는 기존과 같이 설치 시 검증해 다운로드합니다.
자체 MIT 입력 보조 앱만 소스·해시와 함께 포함합니다.

## 검증 범위

자동 테스트 270개와 CLI·TUI·웹 UI의 실제 VM 제어를 확인했습니다.
브라우저에서는 데스크톱/모바일 로그인 상태·Exit node 선택·우회 해제·서비스 오류·닫힌 패널의
늦은 응답 처리를 검사했습니다. 로그인 승인은 사용자가 브라우저에서 직접 수행했습니다.
기존 Exit node를 통해 VM 및 Android 네트워크 공간의 외부 IP와 Android DNS 응답을 확인했고,
카카오톡 채팅 목록·앱 TCP 연결을 확인했습니다. macOS의 IPv4/IPv6 기본 경로와 DNS는 작업 전과
동일했습니다. 실제 메시지 송신은 하지 않았습니다.

이 검증은 모든 네트워크·Exit node의 카카오 접속이나 신규 KakaoTalk 설치 전체 흐름을 보장하지 않습니다.
기존 배포와 같이 preview를 유지합니다.
